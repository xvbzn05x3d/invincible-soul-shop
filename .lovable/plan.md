# План реализации: Роли редакторов, управление товарами и улучшения UI

Внедрение системы ролей для управления сайтом (владелец, редактор), улучшение визуальных переходов и расширение географии доставки.

## Технические изменения

### 1. Безопасность и роли (Supabase)
- **Таблица `user_roles`**: Добавление таблицы для хранения ролей пользователей (owner, editor, user).
- **RLS Политики**: 
    - Только `owner` может назначать и снимать редакторов.
    - `owner` и `editor` имеют полные права на CRUD операции в таблице `products`.
- **Функция `has_role`**: Использование `SECURITY DEFINER` функции для проверки прав доступа без рекурсии в RLS.
- **Исправление безопасности**: Ограничение прав `EXECUTE` на функцию `has_role` (только для `service_role`), чтобы избежать предупреждений линтера.

### 2. Управление товарами (Frontend)
- **Страница профиля**: Добавление раздела "Управление ролями" для владельца (назначение редакторов по email).
- **Интерфейс редактора**:
    - На главной странице и в карточках товаров добавить кнопки "Редактировать", "Удалить".
    - Кнопка "Добавить товар" в каталоге.
    - Модальное окно/форма для редактирования всех характеристик товара (заголовок, цена, описание, категория, статус "новинка").

### 3. Пользовательский интерфейс (UI/UX)
- **Плавные переходы**: Использование Tailwind `animate-in`, `fade-in`, `slide-in` и `backdrop-blur` для более мягкого восприятия блоков.
- **Исправление кнопок**: Замена `Link` на якорные ссылки `<a>` для кнопки "Заказать товар" для корректного скролла к каталогу.
- **Реорганизация футера**: Удаление лишнего раздела "Связаться с магазином" и объединение контактов в блоке "Обратная связь".

### 4. Доставка и заказы
- **География**: Расширение списка регионов и городов в таблице `pickup_points` (СДЭК по всей России).
- **Корзина**: Добавление сортировки регионов по алфавиту в выпадающем списке.
